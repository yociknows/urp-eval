# 都更投報評估系統

- 桌機完整版（PWA，可安裝、可離線）：網址根目錄 `/`
- 手機快篩版：`/quick/`

## 上 GitHub Pages
1. GitHub 建一個新的 repository（例如 `urp-eval`）。
2. 把這個資料夾裡「全部檔案」上傳到 repository 根目錄（Add file → Upload files，拖進去後 Commit）。
3. Settings → Pages → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)` → Save。
4. 約 1 分鐘後網址會出現：`https://帳號.github.io/urp-eval/`
   - 手機快篩：`https://帳號.github.io/urp-eval/quick/`

## 注意
- 資料存在各自的瀏覽器，換裝置請用「匯出／匯入 JSON」。
- 更新版本：重新上傳覆蓋檔案即可，資料不會消失。
- `source/` 是原始碼，不影響網站運作。
